Gradients and underlines

CSS backgrounds and text decorations drawn on the canvas. Resize the window or zoom the page to see them adapt.

Set background: linear-gradient(to right, #17468c, #267b88) on a block. Stops accept percentages and CSS lengths. Rounded corners, transparent colors, and currentColor work too.

# The demo on macOS

Every tab of the demo, from the Cocoa build on macOS Sequoia 15 (Intel)
with Lazarus 4.8 and FPC 3.2.4 - the window as macOS draws it, title bar
and shadow included. To take them again:

```sh
lazbuild --ws=cocoa demo/lazinkdemo.lpi
./demo/lazinkdemo --screenshots images/macos
```
